# Expense Tracker (Python)

Saves your daily expenses and shows the total. Data is saved in a file.

## What it can do
- Add an expense (name and amount)
- Show all expenses and the total
- Delete an expense

## How to run
1. Install Python 3
2. Open a terminal in this folder
3. Run: `python main.py`

## Example
```
1. Rice - $5.00
2. Fuel - $12.50
Total: $17.50
```

## What I practiced
Lists, dictionaries, JSON files, sum(), input checking.
